Quick Definitions

Short explanations of the scheduling metrics.

Average Waiting

Average time processes wait before getting CPU execution.

Average Turnaround

Average total time from process arrival until completion.

CPU Utilization

Percentage of total time the CPU is busy executing processes.

Context Switch

When the CPU changes execution from one process to another.

Completion Time

Time at which a process finishes its CPU execution.

Turnaround Time

Completion time minus arrival time.

Waiting Time

Time a process spends waiting in the ready queue.

Response Time

Time from arrival until the process first gets the CPU.
